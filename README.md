# super-agent

这是用于体验 DeepSeek Harness Superagent 的任务仓库。

## 提交任务

使用已授权的 GitHub 账号 `FBI-6`，在本仓库的 Issue 或新评论中
`@Frz2004`，写明具体目标、修改范围和验收标准。

## 初始使用约定

- 每个任务使用独立的 `agent/` 分支和 worktree。
- 明确要求时创建 draft PR，由人检查后决定是否合并。
- 报告实际执行的检查、结果和未完成的事项。

示例请求：

```text
@Frz2004 请在 README 中新增“使用示例”小节，说明如何给智能体
提交一个范围明确的任务。只修改 README，并创建 draft PR，不要合并。
```
