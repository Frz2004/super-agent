# 后续开发路线

基础版本已经提供真实可运行的前后端、数据库、执行器和测试。以下是继续完善的明确边界，并不是已完成功能。

## 第一优先级：可观测性与规模正确性

- 项目级全量聚合统计，替换最近 100 个任务的 UI 统计。
- 最新活动、历史翻页与任务审计服务端筛选，解决 1000 条事件截断。
- 可搜索分页的依赖选择，保留未加载的已有依赖。
- SVG 依赖图、节点定位与阻塞路径；支持 200+ 节点。
- 精确的 Run 步骤起止时间、尝试历史、错误分类和脱敏导出。

详细验收要求见 SUPERAGENT_NEXT_TASK.md。

## 第二优先级：工作流能力

- 用显式类型和 schema 实现可配置的安全执行步骤，不开放任意 shell。
- 并行分支、汇聚节点、失败传播、暂停/恢复、人工审批节点。
- 单事务的任务完整编辑，避免基本字段与依赖分步保存。
- 可取消的业务副作用与重试补偿策略。

## 第三优先级：工程与可靠性

- 显式版本数据库迁移与备份恢复工具。
- 进程级终止/重启验收、多进程租约或明确的单实例锁。
- SSE 压力测试、背压测试、历史保留与清理策略。
- UI 组件拆分、设计变量、抽屉完整键盘焦点管理、拖动与键盘状态切换。
- 测试覆盖率与性能基线，避免仅增加镜像实现的测试。

## 后续再讨论：多用户部署

登录、权限、用户隔离、TLS、审计保留策略、部署和运维需要独立设计。未经明确授权，不应把本机应用直接发布到公网。
