## 当前明确限制

- 未实现公网多用户认证、权限、TLS、多进程队列租约。
- 看板统计与依赖选项仅加载最近 100 项；活动面板读取最早 1000 条项目事件再倒序，不代表无限历史下的真正最新活动。
- 任务基本信息和依赖编辑分步保存；UI 说明了部分保存的可能。
- Run.steps 只保存当前/最后一次尝试；缺少每步结束时间、完整 attempt 历史和 JSON 导出。
- 默认执行器不会主动制造暂时错误；失败与重试通过隔离测试注入，未开放普通用户的故障控制接口。
- 基础模态框支持焦点循环和 Escape；任务详情抽屉尚缺完整焦点约束。
- 没有依赖图可视化、看板拖动、附件处理或任意代码执行。

这些限制已在路线图及下一轮 Superagent 任务中明确列出。
