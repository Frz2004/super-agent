# 架构与设计取舍

## 模块

浏览器 React UI → Express API → Service → Store / SQLite。

Runner 在同一 Node 进程内调度数据库中的 queued Run，调用内置文本执行器，通过 Store 保存步骤和状态。Store 在事务提交后发布事件，SSE 把持久化事件推送给前端。UI 按事件 ID 去重并重新读取当前资源。

没有内存假数据库，也没有用计时器直接伪造百分比。执行器中的短延时用于让三个实际处理步骤可观察，不代表外部服务调用。

## 持久化模型

| 表           | 用途                                         |
| ------------ | -------------------------------------------- |
| projects     | 项目名称、描述、归档与时间                   |
| tasks        | 项目任务、状态、优先级、标签、乐观锁版本     |
| dependencies | 前置关系，复合主键消除重复                   |
| runs         | 输入快照、队列状态、尝试次数、步骤和结果     |
| events       | 自增 ID 的审计及 SSE 事件                    |
| idempotency  | 按端点/资源作用域保存请求指纹和初始响应      |
| migrations   | 初始 schema 版本；后续变更需增加显式版本迁移 |

开启外键、WAL 和 5 秒 busy timeout。一个任务通过 SQLite 部分唯一索引限制为最多一个 queued/running Run。

## 一致性

Service 使用 `BEGIN IMMEDIATE`，在单个事务内完成业务变更、幂等响应和审计插入。异常回滚后不会广播事件。发布发生在 COMMIT 后；SSE 订阅者只观察已提交数据。

编辑接口要求 version。旧版本返回 409，而不是覆盖新值。Run 入队后，任务编辑被锁定；完成或取消时版本号递增。依赖必须同项目且无环。已有排队/运行/完成后继时，不能把其 done 前置重置为 todo。

创建任务和 Run 可提供 Idempotency-Key。指纹来自经 Zod 规范化后的请求 JSON；键按端点和父资源隔离。相同键重放返回首次响应，因此响应中的状态可能是初始状态，应通过 GET 获取当前状态。幂等记录暂不自动过期。

## 队列、重试和恢复

默认并发 2，允许 1—8。100ms 轮询持久化队列。任务入队时保存描述或标题的输入快照。每次尝试按步骤记录事件；只有 RetryableError 自动重试，使用指数退避，最多 1—5 次。

用户取消先提交 canceled，再中止执行器。成功和失败回调在写入前重新检查 Run 仍为 running，因此晚到结果不能覆盖取消。已取消或失败的任务恢复到 todo，历史 Run 保留。

退出时停止调度并中止活动执行。下次启动，遗留 running 记录标为 failed、写入 run.interrupted、恢复任务 todo；已有 queued（含等待重试）记录继续调度。中断不会自动重新执行 running，从而避免无意重复副作用。需要用户显式重新发起。

当前只支持一个服务进程管理一个数据库；不具备多实例租约。文本执行器确定性且无外部写入，但扩展执行器时仍需设计业务幂等和副作用补偿，不能声称 exactly-once。

## SSE 与审计

GET /api/events/stream 从 Last-Event-ID（优先）或 after 之后回放，按递增事件 ID 发送 `change` 事件。回放和订阅在同一个同步 JavaScript 调用栈内完成，没有异步空隙。所有关键事件均持久化，重连可补收。

15 秒心跳；连接关闭时释放监听器和定时器；发送缓冲超过 1 MiB 时断开，客户端通过持久化游标补收。此版本没有历史保留/清理策略，事件会持续增长。

## 前端

任务板按当前分页结果分列；详情支持编辑、状态操作、依赖关系、执行历史、步骤、结果和审计。EventSource 断线重连使用浏览器维护的 Last-Event-ID。每个项目订阅有独立去重游标，事件批次合并为一次刷新。

当前完整编辑分两次请求保存基本信息和依赖；依赖更新失败时基本信息可能已保存，界面明确提示这一点。下一轮可以增加单事务的完整编辑接口。

## 安全与范围

服务绑定 127.0.0.1，校验 Host 与浏览器 Origin；不启用跨域 API，不执行用户文本中的命令。请求体 64KiB，上限和字段通过 Zod 校验，数据库使用参数化值。API 错误有 requestId；未知错误不向客户端暴露堆栈。

没有认证、用户隔离、限流或公网运维能力。该边界是本机实验平台，不是可直接公开部署的多用户服务。
